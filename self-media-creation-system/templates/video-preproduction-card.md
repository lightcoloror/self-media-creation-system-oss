## 所有视频先填的六件事

- 项目、日期、负责人；账号、主要观众与本条唯一任务：
- 视频形态与预期交付：`口播 / 采访 / 真实操作 Demo / 长视频 / 直播 / 其他`；平台、横竖画幅、拟有的衍生版本：
- 一句话观众问题或承诺；现在已知的事实、仍未知的结果、不能说成既成事实的内容：
- 拍完后观众必须**看见或听见**什么，才可能理解／核对这条内容？逐项写「画面或声音 → 用途 → 来源／责任人」：
- 哪些画面、动作、同期声、人物回答或状态不可补拍？谁在何时负责；若缺失，视频角度如何收窄：
- 人物／场地／产品界面／音乐／第三方材料的许可、隐私和安全疑点；目前状态为 `已核对 / 待核对 / 不拍`，不把“拟拍”当授权：

## 只填本次适用的类型（可多选）

### 真人口播／证据解释

- 已核事实版本、拟讲的主判断与适用边界；口播稿／作者试读／人声确认状态：
- 哪些句子需要本人画面、实拍补画面、可公开证据或自制图卡？证据原件是否已生成获准脱敏衍生件：
- 本次必须现场拍的人声、人物主镜头、动作与专用封面照片；不在镜头中露出的私人资料：
- 真实案例口播仍走既有 `case_video_candidate` 录制前审核、隐私、字幕和成片门；一般口播按其正式内容路由处理，本卡不替代任何适用门。

### 采访／人物故事

- 被采访者是谁（公开版用代号）、采访目的、录制同意与拟公开范围；录制同意未知先不录，公开许可未知先不公开：
- 三个左右开放问题、每题想核对的事实或感受；可能的追问方向（不能预写回答）：
- 需另拍的生活／工作动作、场景、物件、环境声，以及不能进入画面的敏感信息：
- 受访者可能拒答、撤回或提出不同结论时，如何保留原意或收窄成片；客户／医疗／儿童素材另走加严门：
- 正式采访提纲与作者审核仍使用既有 `interview_guide`；本卡只协调拍摄覆盖与风险，不冒充同意回执。

### 产品 Demo／屏幕教程

- 这条视频只演示哪一个真实任务？当前构建／版本、功能状态与可复现的输入：
- 准备无真人敏感数据的测试环境；录屏前检查账号、通知、文件名、后台窗口和网络状态：
- 连续操作链：起点 → 实际输入／点击 → 等待或处理 → 用户可见结果 → 失败／限制。哪些部分是实录、模拟或计划中，片内如何标明：
- 关键 UI 文字、光标／手势、错误提示和同期解说是否能在目标画幅看清听清；不能用跨运行拼接冒充一次成功：

### 长视频／直播（需要时）

- 长视频：各章节分别回答什么问题，所需案例、证据、演示、反例和过渡画面能否取得；缺证据的章节如何缩减：
- 直播：本场边界、可循环话题单元、预备展示素材、互动／无人互动、敏感提问和技术故障应对；不得编造观众提问：

## 开拍／开播前与离场前

- [ ] 本次必需的事实、提纲或真实操作范围已核对；未知结果仍写成问题，不预写采访答案、客户决定或旅行转折。
- [ ] 器材、电量、收音、画幅与足够存储已实测；涉及直播或 Demo 的屏幕内容已做隐私预览。
