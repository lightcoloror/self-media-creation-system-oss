## 变动一：建立唯一字号策略

- **意图**：消除不同流程各自写字号、最终渲染仍然偏小的执行漏项。
- **决策**：按输出 profile 和文字角色规定最低字号；最低字号不是固定字号，实际排版继续按字数与空间自适应，并使用 `max(最低门槛, 自适应首选值)`。
- **理由**：只检查 CSS 常量、设计稿或全尺寸截图，不能证明手机信息流中的真实可读性；同时把最低值写成固定值会破坏短文案的大字层级。
- **证据**：策略文件已覆盖 16:9、4:3、3:4、9:16、1080×1920 动效／字幕、1080×1440 社交卡和文章桌面／移动 profile；策略哈希已由各 consumer 精确绑定。
- **生效范围**：以后所有新建或返工的含文字封面、图文、文章 HTML、竖屏动效、字幕、署名和声明。未改动的历史发布物不自动失效。

## 变动二：MVP Video／Remotion 接入

- **意图**：阻止视频画面和字幕在渲染阶段低于手机可读门槛。
- **决策**：Case Cover、semantic motion 和字幕从 canonical policy 读取角色门槛；字幕最低 48px、motion label 最低 36px；缺策略、画布不匹配、哈希漂移或角色缺失均失败关闭。
- **理由**：字幕、信息标签和封面主文案承担不同阅读任务，不能共用一个无角色的阈值，也不能在后期为了装下内容继续缩字。
- **证据**：`test_typography_gates.py` 5/5、`test_title_cover.py` 13/13；`pytest tests/test_semantic_motion.py -q` 为 23 passed、1 skipped，跳过项仅因本地未安装 `norfair`；`git diff --check` 通过。
- **生效范围**：MVP Video 的候选封面、1080×1920 语义动效与字幕链；不授权自动发布。

## 变动三：Content Studio 图文与文章接入

- **意图**：让图文卡片与文章 HTML 按实际 DOM 渲染结果接受同一门禁，而不是再维护一套阈值。
- **决策**：新增共享 DOM collector，检查所有可见阅读文本的 computed style、角色、边界与 overflow；无法安全归类的阅读节点失败关闭。社交卡使用 `social_card_1080x1440`，文章同时检查 desktop 与 mobile profile，结果写入既有 browser QA 与 render receipt。
- **理由**：只选择 `h1/h2/p` 会漏掉放在 `div/span/button` 中的真实阅读文字；只检查一个视口也会遗漏移动端或桌面端退化。
- **证据**：沙箱外本地无头 Chromium 复验社交卡＋文章正负例 8/8；receipt 3/3、文章主题回归 8/8、医疗官方产物 schema 4/4；Node 语法、Python 编译和 `git diff --check` 通过。新门禁实际拦下原文章桌面 `h2=27px < 30px`，模板最小调整为 30px 后 E2E 通过。
- **生效范围**：Content Studio 的 `social-card` 与 `html-playwright` owner；无真实客户资料、无上传或发布。

## 变动四：当前八条视频三候选封面回归

- **意图**：确认当前比较页不再以小字和过量留白通过内部候选筛选。
- **决策**：比较页只读取权威策略的本地只读派生绑定；每种比例独立重排、独立检查，失败候选禁止选择。
- **理由**：一个比例通过不能证明另一个比例可读；比较页自带阈值会与正式渲染器发生漂移。

## 变动五：跨流程硬门分类

- **意图**：把可客观判定、漏检后果高、能够绑定确切产物的要求统一为阻断条件。
- **决策**：总质量门现统一覆盖：事实与证据、隐私与授权、医疗／保险及分发合规、素材与权利、视觉可用性、音频与字幕、技术完整性、内容承诺一致、发布边界。缺证据、证据过期或与成品哈希不匹配均不得进入下一阶段。
- **理由**：这些问题一旦漏检，可能导致事实错误、隐私泄露、权利争议、不可读、音画错误、承诺错位或越权发布，不能只靠最后一次人工观看补救。
- **证据**：`quality-gates.json` 已落地对应硬门；self-media 三个跨流程正负例 3/3 通过；配方缺门禁或策略缺 profile 时均会失败关闭。
- **生效范围**：自媒体选题、脚本、采访、图文、封面、视频、字幕、包装、审查和人工发布交接。主观审美、流量预测、AI 味强弱及具体动效偏好仍是评分项，不作为无条件全局硬门。

## 验证边界与未解决项
