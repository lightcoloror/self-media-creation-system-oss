# 封面图文融合与动作构图复盘与可复用手册

> **更新日期**：2026-11-26（Asia/Shanghai）
> **适用仓库**：`self-media-creation-system`（关联 `mvp-video-pipeline`）
> **沉淀范围**：基于多轮封面 PK（v1 → v6）实测、开源图文融合项目调研与 P0 工程化落地（`magazine-depth-fusion`）提炼的通用可复用经验。

---

## 一、核心结论（下次做封面直接照着做）

1. **先选动作与物理隐喻，最后才排字**：静态坐姿/看镜头肖像在 `200px` 手机信息流里几乎没有停顿感；必须用**强动势动作 + 具象物理道具**（如飞踢印字沙包、棒球手扬腿狠砸缠绕胶带进震斜垃圾桶、手臂紧贴桌面把杂物一整片铲出桌沿、或三色 Risograph 极简符号海报）承载核心痛点。
2. **禁止“上字下人”割裂安全盒，改用杂志级三层景深融合**：将主体放大至占满画面主视觉区，主标题拉满 `85%–90%` 画幅宽置入中层，用高精度透明前景让**发顶/道具自然压过主标题边缘（单字遮挡 `<= 22%`、标题总遮挡 `<= 18%`）**，底边用实心高对比行动条锁住前景，同时对受保护人脸/眼/标志特征维持 `0%` 硬保护。
3. **单母版跨比例一致性是铁律**：同一候选设计的 `3:4 / 9:16 / 16:9 / 4:3` 必须由同一张锁定视觉母版无缝延展背景后独立重排文字，严禁按比例重抽不同姿势或服装。
4. **单元测试通过 ≠ 视觉过关**：所有封面管线必须跑真图端到端输出，并逐像素目视检查 `200px` 手机缩略图、接缝、遮挡笔画与人物未镜像特征。

## 二、多轮迭代暴露的典型坑与可复用修复模式

| 迭代暴露的问题 | 根因诊断 | 固化后的可复用解法 |
| :--- | :--- | :--- |
| **动作显“礼貌/摆拍”**（如轻轻把胶带放进垃圾桶、手悬在桌面上方像往桌上扔东西） | 提示词只写动作名词，未规定**发力姿势、身体重心、物理接触面与物体受冲击形变** | 提示词必须同时写清 4 要素：① 全身/半身发力重心（如后腿高扬离地、外套飞起）；② 0cm 物理接触面（手臂/手掌紧贴木桌面、鞋底压陷沙包）；③ 可见边界悬崖（桌面左沿留在画幅内，杂物正滚落出桌沿）；④ 受冲击反馈（垃圾桶震斜、粉笔灰/碎纸飞溅）。 |
| **人物和字都很小、彼此割裂** | 原有 `cover_layers.py` 一刀切禁止任何后绘图层与文字框相交，迫使构图切分成上 40% 字块 + 下 60% 缩水人像 | 升级 `cover_layers.py`（`depth_fusion` 显式 opt-in）+ `config/cover-design-recipes.v1.json` 新增 `magazine-depth-fusion` 配方 + `scripts/cover_depth_fusion.py` 逐字像素遮挡测量（`<= 22%`）与有界自动重排。 |
| **顶部扩展负空间反被裁掉** | 给 `3:4` 母版顶部加边后直接用 `fit_cover` 缩放，导致新增顶部空间被居中裁切回原样 | 竖版扩顶必须同步按比例扩两侧以维持精确 `3:4` 宽高比，或用 `zoom_crop_3x4` 直接放大主体走杂志叠层，不再做无效缩图。 |
| **横屏 16:9 延伸桌面时桌沿发糊** | 左侧背景延伸对边缘采样条做了大核垂直高斯模糊（`v_blur=101`），把墙面与木桌面的锐利水平交界线糊掉了 | 含水平桌面的镜头延伸时将 `v_blur` 压至 `3` 或改窄条采样，保持墙-桌分界线锐利如原图。 |
| **AI 直出中文易多笔/少笔，且多比例不可控** | 扩散模型原生文字可控性在多比例与密集行距下仍不稳定 | 分工原则：**主标题/副标/行动条 100% 走本地无损字体渲染**；仅当文字需要**长在实物材质透视上**（如沙包印字）时允许模型直出，且必须逐字核对每一笔画。 |

## 三、开源图文融合与封面 Agent 生态选型沉淀（2026-11 调研基准）

在既有本地审查基线（`gbro-cover-design`、`atutun-xhs-cover`、`baoyu-cover-image`、`canvas-design`、`extract-visual-style-2`、`Ming-Image`）之上，三类真正解决“图文融合”的开源方向及在本系统的落点：

1. **前后景抠像与逆向拆层（P0 已接入架构）**
   - `ZhengPeng7/BiRefNet`（发丝/透明杂物高精度分割，~1.5–2GB VRAM）：已通过 `cover_depth_fusion.py --matting-backend birefnet_onnx` 对接 ONNX 接口（遵循无静默下载红线，传入本地权重即切换）。
   - 本机离线 `RobustVideoMatting (rvm_mobilenetv3.pth)` + 影棚道具 LAB 融合（`hybrid_rvm_studio`）：实测 RTX 5070 秒跑，四比例全过门禁。
   - `QwenLM/Qwen-Image-Layered` / `CyberAgentAILab/LayerD`（ICCV 2025）/ `lllyasviel/LayerDiffuse`：用于把扁平海报拆成可调 Z-order 的 RGBA 图层，平替高显存的 `Ming-Image-0.1-Design-Layer`。
2. **原生图文一体与结构化版面（P2 按需试用）**
   - `alimama-creative/PosterMaker`（CVPR 2025）、`QwenLM/Qwen-Image`、`AIGText/Glyph-ByT5`：适合文字长在物体表面或强艺术字场景。
   - `graphic-design-ai/creatiposter`、`posterllava/PosterLLaVA`、`cyberagent/opencole`：MLLM 输出结构化图层 JSON + 背景生成，与本地 `self-media.cover-design.v1` JSON 母版天然对齐。
3. **Agent 视觉自检闭环（P0 已吸收思路）**
   - 参考 `Any2Poster`、`langchain-ai/design-agent`、`Yaxin9Luo/AutoDesign`、`beatra-ai/ai-poster-maker-skill`：用确定性渲染 + 量化指标（单字遮挡、主体面积占比、标题宽度占比、`200px` 缩略图导出）形成闭环，而非一次性盲出图。

## 四、标准复用命令（P0 杂志叠层四比例出图）

```powershell
python -X utf8 -B scripts/cover_depth_fusion.py `
  --master "<锁定无字视觉母版.jpg>" `
  --out-dir "<输出目录>" `
  --prefix "cover_candidate" `
  --ratios "3:4,9:16,16:9,4:3" `
  --tag "账号栏目标签" `
  --lines "第一行巨字|第二行巨字" `
  --cta-main "底边行动大字" `
  --cta-sub "副标说明" `
  --matting-backend auto `
  --max-occlusion 0.22
```

验收基线：回执 JSON 中 `occlusion_audit.passed == true`、`vlm_visual_critique_checklist.overall_automated_pass == true`，且必须人工目视核对每个比例的 `*_mobile200px.png` 与原图主体边缘。
