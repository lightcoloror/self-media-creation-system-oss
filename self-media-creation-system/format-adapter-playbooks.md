# 格式适配剧本：同一事实如何按不同形式成文

> 先确定消费方式，再叠加平台。以下是结构卡，不是必须照抄的文案公式。

## 朋友圈短文

`一件刚发生的事/观察 → 一点发现或反应 → 自然停住`

- 关系触达，不承担完整科普、转化或案例证明。
- 允许不对称、留白和没有结论；不自动加标题、CTA 或“慢一点/稳一点”式收尾。
- 图片只留一句大致描述，不默认保存文件引用。

## 图文笔记

`封面承诺 → 为什么会卡住 → 核心判断 → 过程/清单/证据 → 边界或最小行动`

- 每页只完成一个认知任务；正文补背景、边界、来源，不复读图片。
- 灿哥精进多用“抽象问题 → 场景化工具”；灿哥诊风险多用“现实处境 → 问题拆解 → 服务路径”。
- 视觉由主题和阅读任务决定：亲子、技术、个人叙事、风险解释不能只换颜色。

## 短视频口播

`受众此刻的情境 → 为什么值得听 → 一个主判断 → 两三个节点 → 边界/结果`

- 一句只说一个意思；脚本必须同时给出口播、字幕重点、画面/B-roll、事实边界。
- 朗读测试比书面阅读重要；不要直接朗读八页图文。
- 当前拍摄优先级：清楚的人声、可见的人脸、准确字幕；不是 4K 或复杂运镜。

## Demo 视频

`真实使用困境 → 原方式卡点 → 实际输入 → 系统处理 → 用户看见的结果 → 已做到/尚未做到 → 协作请求`

- 图语家等产品内容必须分开“已实现”“Demo 中模拟”“计划中”。
- 以真实界面、真实输入和失败边界为证据；不拿抽象愿景替代演示。

## 采访视频

`授权与公开范围 → 受访者的具体处境 → 开放问题 → 追问事实与感受 → 受访者自己的结论 → 事实核验`

- 不替受访者写结论，不把剪辑做成广告证明。
- 医疗、理赔、儿童与客户素材默认 P2：去标识、授权、时间线和截图均需复核。

## 长视频

`本期承诺 → 章节地图 → 证据/案例 → 反例或限制 → 分段回收 → 最终回答`

- 标题、封面、开场必须兑现同一个承诺；每一章用案例、画面、提问或小结重新建立注意力。
- 适合完整解释，不能靠拉长短视频凑时长。

## 直播

`留人开场 → 本场边界 → 可独立重复的话题单元 → 互动 → 新观众复述 → 下一单元 → 收束`

- 它是循环节目，不是从头讲到尾的课程。
- 预先写好：无人互动、敏感问题、个案医疗/保险问题、设备故障的处理句。
- 不编造观众提问、不制造稀缺或恐慌、不用“评论区扣字”诱导式互动。

## 长文/公众号

`准确标题 → 主信息 → 必要背景 → 分节回答问题 → 证据或案例 → 限制与未知 → 来源`

- 允许完整过程和证据；案例、科普、观点要分开。
- 医疗保险内容的事实门应严于短内容；不能靠“看起来专业”的术语替代解释。
