# Public owner boundaries

The existing framework resolves metadata for selected routes. Its registry may
describe an owner that is absent or whose full consumer is not public yet.
Discovery and `doctor` validate local contracts; neither proves that an owner
command ran, a service is available, or a media/content candidate is approved.

Use `tools/public_toolchain.lock.json` for the reviewed public source commits.
Clone owners separately into the indicated directories only when needed.
The configuration helper does not clone, install, start a server, or call models.
Missing consumer scripts and missing evidence remain blocking errors.

- ContentStudio provides evidence/article/case contracts, saved-capture and
  selected-delivery/context consumers, and optional local WeChat formatting.
  Other workbench scripts remain separately under review. The formatter calls an
  independently supplied pinned external runtime; its code/assets are not bundled.
- QRP provides candidate evidence projections. Candidate sources never become
  verified facts merely because hashes or schema validate.
- VKP provides source-time review and metadata. Its public source edition has
  not established the private main workflow's complete context consumer.
- The complete MVP consumer is not included. `local-rough-cut` P0 is a narrower
  FFmpeg tool and is not a drop-in substitute. P1 requires its separate review.
- Artifact lifecycle operations remain explicitly selected local operations;
  an archive plan does not authorize deletion or prove an archive exists.

Provide your own source evidence, author identity and scoped author confirmation.
No example grants publication, account access, external contact or medical advice.

Gateway and VKP public components retain AGPL-3.0; other separately installed
owners retain their own licenses. This workspace includes first-party
consumer glue and reviewed contract resources, not those external runtimes.
