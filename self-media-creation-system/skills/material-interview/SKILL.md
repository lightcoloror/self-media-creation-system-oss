# 素材访谈

目标是帮助受访者说清值得表达的内容，并取得足够写作的真实材料。问题服务于本次内容，不以问满表格、制造情绪或讲成完整励志故事为目标。

## 接入与模式

先读取本次目标、此前回答与用户纠正，沿用已知受众、形式、篇幅和公开范围。关键目标缺失才问。内容方向可暂定；素材不足时先收集，不强行通过故事设计或生产门禁。

标题、选题措辞和活动主题可能由主办方或编辑提出。按已有信息区分提出者、暂定状态及可修改范围；不要默认是受访者亲自命名，也不要从标题推导其情感、动机或要求解释象征意义。

- **经历访谈**：理解实际处境、行动、可观察结果及本人解释；场景细节只补影响理解的部分。
- **观点访谈**：明确主张、依据、例子、适用范围和不同意见；不要求每个观点都有戏剧化个人经历。
- **正式采访提纲**：按目的准备主问题及条件式追问，沿用 `case-interview-guide.v1` 与具体问题的人审；不预写答案。提纲是备选，不是现场逐项必问清单。

普通聊天式素材提炼直接在当前对话进行，适用于图文、口播与演讲，不要求先建立录制任务或事实卡。需要正式 managed handoff 时仍走原有五流程的相应步骤。取得材料后，按现有 `creation-route` 判断进入故事或说明等写作路线，不因“采访”自动选故事。

## 每轮如何决定

在工作上下文中维护简短材料摘要：已说清的事件/观点、本人解释、记不清或未核实的部分、真正影响成稿的缺口。可在当前对话保留，不默认写入数据库。用户改口时更新，不把此前猜测升级为事实。

提出下一问前，判断：它在补哪个缺口？答案会改变主线、事实准确性、重要例子或表达边界吗？此前是否已经答过？若没有明确用途，就删掉。不要把内部表格或完整待问列表每轮呈现给用户。

连续访谈每轮默认只问一个简短、具体、中立的问题，接住受访者刚才的话，等回答再决定下一问。可以简短说明提问用途。受访者应说得更多；不打断正在展开的叙述，不每轮重复总结或评判。

- 需要新材料时用具体的开放问题；核对关键事实时可用封闭问句。不要把多个独立问题塞进一句话，也不要固定按“场景→对白→感受→意义”走一遍。
- 不提示“正确答案”，不问带结论的“所以你终于释怀了吧”。区别亲眼所见、本人推测、转述和编辑解释；第三人的内心与动机不能由旁观者代填。
- 用户已说清行动和结果，就不再问同义问题。感受可问，但只在影响本次表达且未说明时问；不逼受访者给情绪命名、精确原话、惯用语或标题象征。
- “不记得”“没有”“没什么”也是答案。非关键细节记录未知并略过；关键歧义可换一种容易回答的方式核对一次，仍无答案就留空、查授权资料或删除相关断言。不要用追问次数换确定性。
- 用户说问题奇怪、过多或累了，先承认当前问法问题，整理已有材料并缩小剩余缺口；若已足够就停止。用户要暂停或改做别的任务时立即停止。

追问菜单只在对应缺口存在时选一个，例如：事件过程缺失时“你接着做了什么？”；结果来源不清时“你是通过什么判断事情解决了的？”；观点边界不清时“这种做法在什么情况下不适用？”这些不是必问步骤。

## 什么时候收口

目标已清楚，现有材料能支持一条内容主线，关键断言有依据或能如实保留未知，就足以进入写作。无需搜齐所有细节，也无需规定必须有几个故事、几句金句或几个转折。

收口时给一段简短的候选主线和少量关键缺口，让用户纠正或选择。用户已确认方向或明确要求直接写，就按已有授权推进；不再重复确认。若方向未定，先确认影响写作的那个选择。不给没有实测的试读时长。

不强凑圆满结局、人物成长或工具成功。某次沟通有帮助不等于工具已经被采用；沉默、不再争论不等于理解或同意；演示功能不等于持续使用。主体自己的风险判断不能写成普遍专业建议。

## 授权与后续

沿用用户已明确的公开范围，不重复索要同一确认。受访者可跳过或停止；提纲审核、录制同意、涉及他人的素材使用与发布许可分别按现有规则处理，不因本 Skill 新设一套批准流程。真实私密材料不写入公共 fixtures，也不默认外发、入库或发布。

结束后把已知、推断、未知和忠实转述带进既有事实整理、作者修订与审核。内容整理不自动批准录制或发布。

## 依据与本地适配

核对：2026-10-11（Asia/Shanghai），Codex（GPT-6）。下面是方法来源，不是平台效果证明。

- [British Library 口述史负责人 Rob Perks 的访谈建议](https://www.heritagefund.org.uk/blogs/learning-listen-top-tips-great-oral-history-interview)：倾听、不评判、尊重跳过与停止，区分事件讲述和后来解释。
- [Self Evident：Asking Thoughtful Interview Questions](https://selfevidentshow.com/oral-history-toolkit/lesson-06-asking-thoughtful-interview-questions)：根据受访者已分享内容提问，以开放问题探索，按回答追问；封闭问题可核对细节。
- [Oral History Australia 实务指南](https://oralhistoryaustralia.org.au/guidance/practise/)：知情同意与伦理贯穿访谈及后期使用。
- [本地 grill-me 的来源与适配说明](../../../skills/grill-me/references/upstream-notes.md)：借鉴问题相关性和及时停止；不调用方案盘问流程、不推荐受访者应当给出的故事答案。

单轮一问、非关键遗忘停止追问、足够材料即收口，是为自媒体对话作出的本地操作性综合。没有照搬口述史长访谈的固定题数；招聘 `interview-designer` 不适用。
