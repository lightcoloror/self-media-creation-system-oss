## 在系统中的位置

```text
事实与边界 → 任务路由 → 格式与平台 → 声纹/视觉
→ 可选“叙事与共鸣镜头” → Skill → 质量闸门
```

它只在内容确实需要人际理解、个人观察或故事承载时启用；工具说明、规则答复、紧急信息、医疗保险事实澄清不要求强加情绪线。

## 采用的四个原则

1. **具体先于抽象**：用已经发生、可核对的动作、物件、对话片段或场景，代替“很感动”“很焦虑”这类空泛标签。
2. **感受不等于煽情**：可说“被想起的感觉还挺好”，不需要再把它升级为人生道理。
3. **从我到读者，是邀请不是操控**：让读者有空间代入；不替读者规定“你一定也……”或预设其创伤、恐惧和缺失。
4. **受控自我表露**：只公开对内容理解确有帮助、且自己愿意长期留在公开场域的部分；真实不等于暴露细节。

## 共鸣镜头卡（仅在有必要时填写）

```yaml
resonance_use: none | contextual-understanding | personal-reflection | emotional-story
observable_detail: 一个真实且可公开的细节；为空也可以
human_tension: 处境中的矛盾或未解决问题，不等同于“冲突必须升级”
felt_response: 我实际感受到什么；不替读者写感受
reader_bridge: 读者可从中理解或使用什么；不是强制升华
disclosure_boundary: 哪些人物、时间、地点、材料不能公开
ending_mode: stop | open-question | next-action | factual-boundary
```

`ending_mode` 默认不是“温暖收尾”或“金句”。内容可以停在事实、一个问题、一个动作或适当的边界。

## 可以保留的“共鸣内核”，但只作为选题提示

“被理解/被记得”“自主选择”“归属感”“成长与遗憾”“照顾与责任”等，可以帮助提问：这件事为什么对我有意义？

它们不能成为硬性公式，更不能默认套入“爱与失去、恐惧与勇气、奋斗逆袭、生命死亡”等高强度主题。特别是医疗、保险、儿童内容，不能用恐惧、绝望或不公作为点击诱饵。

## 明确不采用

- 无来源的镜像神经元激活比例、毫秒数及“神经科学证明内容更打动人”等表述。
- 把英雄之旅、冲突—高潮—解决、反差—小胜利、孤独—温暖收尾当成每篇必走结构。
- 用“创伤后成长”要求当事人从困难中找礼物，或把病痛、理赔、家庭困境包装为励志素材。
- 强制使用金句、治愈结尾、宏大意义、读者情绪预设或“你也一定”式代入。
- 为了画面感虚构气味、动作、对话、客户反应或个人细节。

## 四问自检

1. 去掉情绪词，这件事还真实吗、还讲得清吗？
2. 这个具体细节是我知道且允许公开的吗？
3. 它帮助读者理解处境，还是只是在推高情绪？
4. 停在这里会不会比再加一句“道理/治愈/CTA”更像我？
