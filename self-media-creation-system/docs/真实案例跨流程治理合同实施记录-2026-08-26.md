# 真实案例跨流程治理合同实施记录

更新时间：2026-08-26 23:51:02 +08:00  
执行工具／模型：Codex (GPT-5.6 Sol)

## 总体边界

本次不采用“每句脚本对应一个事实编号”。一般事实继续使用场景级、段落级证据引用；金额、日期、治疗节点、保险责任等高风险信息使用独立事实对象。新增代码只负责合同校验、碰撞检查和删除计划，不重新实现 ASR、转写、翻译、渲染、FFmpeg、发布或客户沟通。

## 变动一：金额语义事实账本

- 意图：防止收费项目、就诊总费用、实际支付、理赔金额、周转资金和借款金额再次被混写。
- 决策：新增 `case-financial-facts.v1`，每笔金额只记录一次，并明确 `amount_role`、阶段、范围、精确金额、公开概数区间、证据状态和证据哈希；脚本只在场景级引用 `fact_id`。
- 理由：金额错误通常不是数字抄错，而是数字的业务语义被替换。逐句事实编号既不能解决语义混淆，又会增加维护负担。
- Public boundary: use source-bound facts and actual service actions; private implementation examples are excluded.
- 生效范围：以后所有出现医疗费用、保费、赔款、现金流或借款金额的案例稿、证据卡、封面和发布文案。

## 变动二：跨语言字幕人工复核回执

- 意图：保证粤语等原声的普通话字幕既忠实，又不脱离真实声音时间。
- 决策：新增 `localized-subtitle-review.v1`。源音频哈希、原文、译文、说话人、源语音时间段、风险标签和人工确认状态必须绑定；译文继承原声话语边界，机器翻译不得成为时间轴权威。
- 理由：翻译稿适合决定显示文字，不适合重新估计声音何时出现；两者混用会造成字幕提前一至两秒。
- 证据：合成测试覆盖人工确认、时间重叠和同语种误用；现有 VKP／本地 ASR 继续负责源音频时间点。
- 生效范围：所有源语言／方言与显示字幕语言不同的采访、口述、客户原声和多语种视频。

## 变动三：产物生命周期与删除门禁

- 意图：集中清理中间版本时避免误删原始素材、精剪素材、客户资料和锁定母版。
- 决策：新增 `artifact-lifecycle-manifest.v1`。产物标记为原素材、已审核源、精剪、候选、锁定母版、被替代、废弃或待归档；删除工具只生成 `quarantine_only` 计划，不直接删除。锁定、客户敏感、仍被下游引用或状态不允许的对象一律阻断。
- 理由：文件名和“新版／旧版”不足以表达依赖关系；永久删除不应与盘点、审查混在同一步。
- 证据：合成测试证明原素材删除被阻断，已废弃且无人引用的非敏感产物只生成隔离计划，未执行文件变动。
- 生效范围：所有自媒体视频、采访、字幕、封面、证据图、发布包及其返工版本。

## 变动四：通用多平台发布包

- 意图：把本项目的五平台上传页面从一次性产物升级成可复用合同，同时防止 AI 味简介、字段缺失和平台限制过期。
- 决策：新增 `platform-publication-package.v1`。每个平台分别记录视频与封面哈希、比例、候选数、长短标题、简介、标签、合集名称与简介、定时时间、规则来源状态、检查时间、人工文案和预览状态；自动发布固定为 `false`。
- 理由：同一视频可以同步分发，但元数据、裁切和当前账号功能不能无审核地继承；平台限制具有时间性，必须同时保存来源状态和检查时间。
- 证据：合成测试覆盖标题超限、文案未人工复核、封面比例／候选数、定时提前量和未知规则；现有项目特定 HTML 仍可作为查看器，不成为自动发布器。
- 生效范围：小红书、视频号、B站、抖音、快手及后续显式加入的人工发布平台。

## 变动五：最终布局全图层安全门禁

- 意图：避免单个动效通过检查，但最终字幕、声明、署名、人物小窗、证据或二维码在手机圆角和平台控件下仍被截断或互相遮挡。
- 决策：MVP Video 新增 `final_layout_safety.v1` 和 `video-final-layout-safety`。所有实际存在的关键图层都要提供时间范围和归一化矩形；每个视频声明必需角色。门禁检查四个圆角、平台保留区、缺失角色、同一时间的关键图层碰撞和输入哈希。
- 理由：安全区不是静态页面边距，而是随时间变化的最终合成问题；同一位置在不同时段复用应允许，同时出现则必须检查。
- 证据：复用了 `privacy_exclusion_zones.py` 的矩形归一化和交集计算；新增 6 项测试，现有隐私、语义动效和生产策略聚焦回归为 44 通过、2 个因未安装可选 Norfair 而跳过。
- 生效范围：竖屏真人口播、采访、证据满屏、人物小窗、信息动效、字幕、水印、执业信息、AI 标签、声明、CTA 和二维码。

## 路由接入

1. 脚本投影步骤先调用案例治理校验器，再写场景级脚本；不增加逐句事实编号。

4. 总质量闸门新增金额语义、跨语言回执、生命周期、最终布局和平台发布包五项检查。

## 未自动化的人类判断

- 金额属于哪个业务角色及证据是否真的支持它；
- 翻译是否改变客户原意；
- 人脸属于谁；
- 发布当天账号界面实际提供什么功能；
- 口播、简介和标题是否自然并适合发布。
