## 高风险升级

- 医疗、保险、理赔、儿童、客户或家属：先做事实卡与隐私边界，再写稿。
- 涉及当前平台规定、工具版本、价格、产品能力：先查官方或一手来源，登记检查日期。
- 涉及真实客户：没有匿名化或公开授权，Skill 只能处理抽象结构，不能接收可识别材料。

### 保险医疗客户案例的固定顺序

`事实卡 → Storycraft 初稿 → 十一门初稿检查（含分发合规） → 内容/AI痕迹诊断 → 实际口吻改写 → 作者朗读确认 → 冻结正文后Hook → 稳定脚本六道合规门 → 候选视频 → 精确成片合规门 → 人工发布与归档`

- Skill 不能把科普、私域或不点产品名判为当然豁免；
- 客户接受采访、正面出镜或不要求打码变声，不等于允许全部敏感信息和任意剪辑公开；
- 稳定脚本回执只放行候选制作；
- 精确成片门必须绑定实际账号、机构批准、客户最终确认、广告/AI标识和最终视频/字幕/封面/发布文案；
- 任一内容变化后重新审核，发布保持人工。
