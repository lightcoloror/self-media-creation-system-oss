# 内容作用机制：共鸣、证据型槽点、受众嘴替与行动型价值认同

> 状态：v1.0 人工执行卡
> 更新时间：2026-07-30
> 执行者：Codex（GPT-5.6 Sol）
> 边界：这些是表达机制，不是每篇必装的“爆款组件”。允许 `none`；不预测流量，不制造敌人，不伪造用户语言。

## 先做选择

每篇最多选择一个主机制和一个辅机制。四种机制都不适合时，选 `none`。

| 机制 | 读者获得什么 | 更适合的任务 | 最低证据要求 |
|---|---|---|---|
| 情绪共鸣 `emotional-resonance` | “你写出了我经历过的感觉” | 关系触达、个人故事、服务过程 | 一个可观察场景；作者确实经历或有授权 |
| 证据型槽点 `evidence-backed-friction` | “原来大家习惯的做法在这里会失效” | 误区澄清、流程解释、讨论 | 常见认知与现实结果之间有可核证的不一致 |
| 受众嘴替 `audience-voice` | “这正是我想问、但没说明白的问题” | 问答、搜索发现、选题、标题 | 真实提问、搜索词、访谈或已审阅记录；不能只靠猜 |
| 行动型价值认同 `value-alignment` | “我认同你在这个取舍中的选择” | 建立信任、个人叙事、案例复盘 | 有真实决策、行动、代价或边界，不能只有口号 |

不要根据“哪个更容易爆”选机制。先看 `primary_audience + primary_goal + source_basis`，再判断有没有足够证据。

## 1. 情绪共鸣

成立条件：

1. 先有具体处境，再有情绪名称：发生了什么、当时看到或做了什么。
2. 保留真实张力：想做什么与现实限制之间有什么距离。
3. 情绪强度不得超过事实强度；不替读者诊断情绪。
4. 自我披露只到完成本篇目的所需的程度；不消费客户、患者、家属或儿童的创伤。
5. 结尾给读者留出空间，可以停在一个动作、发现或余味，不强迫升华。

```text
可观察场景
→ 人在其中遇到的真实张力
→ 作者当时的反应或后来才明白的事
→ 给读者的一座小桥
→ 适时停住
```

适合你的例子：朋友圈“别人介绍着其他保险从业者，对方反而想起我”适合走轻共鸣。重点是“被记得的感觉”，不是把它扩写成客户信任宣言。

失败模式：

- 用“成年人都不容易”“你不是一个人”等通用句替代场景。
- 为了共鸣补造对话、痛苦和戏剧转折。
- 每篇都收束到“慢一点、稳一点”。
- 把悲伤、焦虑或愤怒当作传播按钮。

## 2. 证据型槽点

“槽点”在本系统中改名为“证据型槽点”。它不是骂一个人或群体，而是指出一个可检验的认知、流程或工具失配。

成立条件：

1. 能准确复述常见认知，不能先做一个容易攻击的稻草人。
2. 有现实证据说明它在什么条件下失效。
3. 说清谁因此付出什么具体成本。
4. 给出更准确的模型、判断条件或下一步，而不是只留下愤怒。
5. 医疗、保险、亲子内容默认使用“误区澄清”语气，禁止高唤醒争议优化。

```text
大家通常以为……
→ 但在这个真实条件下……
→ 因此会漏掉/误判/多付出……
→ 证据是……
→ 更准确的理解或做法是……
```

适合你的例子：“理赔不是治疗结束以后交张发票就行”可以成立，但正文必须展示治疗前确认、过程中留存材料、治疗后申请分别解决什么问题；不能扩写成“很多保险从业者都不专业”。

失败模式：

- 以“所有人都被骗了”“同行不会告诉你”制造敌我。
- 把个案当普遍规律。
- 只截取不合理的一面，省略合同、医疗或现实条件。
- 争议带来互动后，就把互动当作观点正确的证据。

## 3. 受众嘴替

嘴替不是“替受众宣布态度”，而是把已经存在的疑问、顾虑或目标说得更清楚。

证据等级：

1. `A`：已回看原始聊天、录音、评论或搜索记录，可逐字引用且已脱敏。
2. `B`：由多条真实材料归纳，经过轻度标准化；必须标记为“归纳表达”，不能加引号冒充原话。
3. `C`：同行转述、AI 整理或作者猜测；只能作为待验证假设，不能标成高频问题。

```text
原始表达/归纳表达
→ 触发情境：什么时候会问
→ 表层问题：嘴上问的是什么
→ 实际任务：他想完成什么判断或行动
→ 阻碍：信息、能力、风险或心理顾虑
→ 公共表达：保留原有词汇，去标识，不替他加结论
```

适合你的例子：“我已经有医保了，为什么还要买百万医疗险？”可以来自真实问题素材池。若原文未逐条复核，应写成归纳后的常见问法，不写成“客户原话”。回答先处理“已有保障与新增保障分别解决什么”，不要先推产品。

嘴替只负责确认“客户会怎样问”，不自动推出需要重构。问答型内容先按 [问答选题分流与条件式重构操作卡](./topic-reframing-playbook.md) 判断：问题准确就直接回答；只有原问遗漏关键前提、会误导决定时，才把原问作为入口并向前重构一层。

失败模式：

- 把作者想卖的方案写进“用户需求”。
- 把一两个问题说成“所有人都在问”。
- 为了像真人，编造口头禅、评论和客户引语。
- 把隐私、疾病、财务状况或家庭关系从问题中推断出来。

## 4. 行动型价值认同

价值认同不是写一句正确的话让读者表态，而是让读者从真实选择中看见你的判断标准。

成立条件：

1. 有一个真实决策点，至少存在两个合理选项。
2. 说明取舍：选了什么、放弃什么、为什么。
3. 展示行动以及它带来的成本、限制或后果。
4. 原则从行动中归纳，不凌驾于事实之上。
5. 允许读者不认同；不把不同选择的人写成不负责、不清醒或不善良。

```text
当时要决定什么
→ 有哪些可选路径和现实约束
→ 我/当事人实际做了什么
→ 承担了什么代价或边界
→ 这件事反映了怎样的判断标准
→ 不强迫一致
```

适合你的例子：癌症诊治案例可以通过“医疗判断交给医生和患者家属，我负责把保障、医院范围、现金流和材料衔接清楚”体现价值观。价值来自角色边界和实际动作，不来自“我比只卖产品的人更负责”。

失败模式：

- 只有价值口号，没有决策和动作。
- 把个体选择包装成唯一正确答案。
- 用身份标签筛选“同类”，制造道德优越感。
- 价值表述与长期发布行为不一致。

## 机制选择与平台适配

| 场景 | 主机制建议 | 平台/形态提醒 |
|---|---|---|
| 朋友圈真实片段 | 情绪共鸣或行动型价值认同 | 信息密度低；可以没有标题和 CTA |
| 小红书真实问题问答 | 受众嘴替 | 标题可直接使用经核验的归纳问法；正文补边界与解决路径 |
| 小红书流程误区 | 证据型槽点 | 封面点出失配，后续页必须兑现证据和修正模型 |
| 口播案例 | 共鸣或价值认同 | 开场兑现题目；用留存拐点验证结构，不把稿子读成图文 |
| 长视频/公众号 | 主机制任选一个 | 可以补充反例、证据、限制条件，不靠重复情绪维持篇幅 |

## 发布后怎样验证

先验证“机制有没有被读者接收到”，再看流量。内容信号与业务信号分开：

| 机制 | 更直接的内容信号 | 不应得出的结论 |
|---|---|---|
| 情绪共鸣 | 读者用自己的经历回应；转述了核心感受；视频相关段落没有异常流失 | 点赞少＝没有共鸣 |
| 证据型槽点 | 读者能准确复述“原认知—失配—新模型”；出现高质量追问、收藏或转发 | 评论争论多＝观点正确 |
| 受众嘴替 | 新评论/私聊出现相同问法；搜索词、真实问题和标题语言逐渐收敛 | 一个问题有人问＝高频 |
| 行动型价值认同 | 读者复述的是你的取舍标准或服务边界，而非一句口号 | 熟人点赞＝价值观已建立 |

执行规则：

1. 一次只改变一个变量，例如机制、开头或证据顺序。
2. 记录发布后 48–72 小时和第 7 天；平台没有数据就如实记 `no_signal`。
3. 视频看选择观看、留存、满意度及具体峰值/流失点；图文看收藏、分享、有效评论和后续真实问题。
4. 朋友圈没有曝光/阅读数据，不承担机制定量验证；可作为关系触达和真实表达样本，由公域内容补充结构验证。
5. 不将内容信号直接归因为咨询、转介绍或成交；只有明确来源事件才能进入业务信号。

## 质量否决

出现任一项就撤回该机制，改成普通清晰表达：

- 证据不足，只能靠加强语气成立。
- 需要伪造引语、冲突、评论或人物反应。
- 需要暴露敏感身份或时间线才能获得效果。
- 标题的情绪、争议或价值判断超过正文能证明的范围。
- 对疾病、理赔、儿童或家庭风险使用恐惧、羞辱、敌我或道德压力。
- 主机制无法用一句话说明，或同时塞入三个以上机制。

## 证据来源与适用边界

- [ONS：Identifying user needs](https://service-manual.ons.gov.uk/content/writing-for-users/user-needs)：用户需要应基于证据，不基于假设；可用分析、测试、访谈、调查和搜索词验证。
- [GOV.UK：Learning about users and their needs](https://www.gov.uk/service-manual/user-research/start-by-learning-user-needs)：使用真实用户熟悉的语言；非用户来源的意见应先视为待验证假设。
- [Berger & Milkman, 2012](https://journals.sagepub.com/doi/pdf/10.1509/jmr.10.0353)：分享与情绪唤醒、实用性和惊奇等因素相关；不能据此推出“制造愤怒就会成功”。
- [van Laer et al., narrative transportation meta-analysis](https://openaccess.city.ac.uk/id/eprint/16984/)：故事与受众熟悉度等条件会影响叙事沉浸；用于支持具体、可进入的情境，不支持强制戏剧化。
- [Brady et al., 2017](https://doi.org/10.1073/pnas.1618923114) 与 [Rathje et al., 2021](https://doi.org/10.1073/pnas.2024292118)：道德情绪和外群体敌意在特定政治社媒语境中可推动扩散/互动；本系统将其作为“平台激励可能奖励敌意”的风险证据，不把政治研究的效应量迁移到保险、医疗或亲子内容。
- [Escalas & Bettman, 2005](https://academic.oup.com/jcr/article-abstract/32/3/378/1867214) 与 [Shared Reality review](https://pmc.ncbi.nlm.nih.gov/articles/PMC9786704/)：身份一致性和共同理解有助于连接；在本系统中落实为可观察选择与共同判断，不落实为贴标签和强迫站队。
- [YouTube 推荐表现说明](https://support.google.com/youtube/answer/16559650?hl=en) 与 [观众留存关键时刻](https://support.google.com/youtube/answer/9314415?hl=en)：区分吸引、参与和满意；标题/封面承诺应由开场兑现，并以峰值、流失点和相似长度内容作结构复盘。该指标只直接适用于 YouTube，其他平台只能借鉴验证思路。
