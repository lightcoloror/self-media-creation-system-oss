# Optional title-matrix method

The framework retains one title/cover/opening route. A separately obtained
title-matrix Skill can help compare candidates after the current body, audience
and purpose are bound. It does not replace author decisions, evidence checks,
factual delivery of the title promise or the applicable human gate.

The upstream Skill and its installation are not bundled. The public edition
does not distribute private manuscript exercises or claim title CTR, follower,
consultation or conversion improvement. Acquire any optional Skill separately
and check its own license and current authority before use.
