# 平台与包装分工

平台适配改变信息密度和入口表达，不改变事实、程度和结果。没有必要强制每个平台换角度；同一标题合适时可以复用。

| 入口 | 优先考虑 | 需要验证 |
|---|---|---|
| 短视频信息流 | 一眼能认出谁遇到什么事；标题/封面给期待，口播开头接住 | 标题承诺是否在开头说明并在正文兑现，封面是否扩大结论 |
| B站/长视频 | 对象、具体问题、故事或内容范围 | 个人经历是否被写成完整教程，篇幅是否支撑“大全”等词 |
| 小红书 | 读者问题与具体经历/可获得的信息 | 是否确有清单、步骤或经验；公式只提供角度，不填补缺失事实 |
| 公众号 | 阅读动机、文章主线、作者判断的依据 | 大标题与摘要是否一致，疑问有没有得到回答 |

这是编辑判断，不是平台算法结论。字符数可以实算；输入长度限制、折叠方式等易变事实在实际发布编辑器或官方文档核验，记录日期。不能用旧笔记充当当前规则。

保持自然说话的力度。吸引力可以来自具体行动、真实阻力、信息差，不必靠“震惊/骗局/崩溃”。保险、医疗标题沿用项目专业边界和平台审核，换词不能消除内容本身的审核问题。
