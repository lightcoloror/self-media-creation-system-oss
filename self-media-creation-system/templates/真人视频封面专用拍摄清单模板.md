## 三、证据主导型必备素材

- [ ] 使用截图、扫描件或清晰照片的原始高分辨率副本；
- [ ] 单独生成不可逆脱敏衍生图，不在封面渲染阶段临时重新打码；
- [ ] 记录来源哈希、衍生图哈希、允许显示字段和禁止显示字段；
- [ ] 金额、时间、条款或流程确实是本条内容的核心证据；
- [ ] 完整证据与局部特写分别准备；
- [ ] 缩小后仍能辨认关键字段；
- [ ] 真人不是必要主体时，不为了统一模板强行加入人物。

## 四、现场拍摄质量

- [ ] 优先使用照片模式；无人协助时使用三脚架、遥控或定时拍摄；
- [ ] 镜头清洁，眼睛合焦，曝光不过亮或过暗；
- [ ] 避免贴近手机广角镜头造成脸部畸变；
- [ ] 人物与背景有清楚分离，但不使用统一网红滤镜；
- [ ] 构图比最终裁切略松，给不同尺寸保留移动空间；
- [ ] 横版和竖版分别拍摄，不依赖同一张照片硬裁全部平台；
- [ ] 背景保持真实、普通、整洁，不出现隐私和误导性职业场景；
- [ ] 拍完立即检查一张竖版和一张横版的清晰度、表情和裁切余量。

## 五、素材入库与后期

- [ ] 原始照片只读保留；
- [ ] 每张候选记录内容编号、构图方向、表情、素材来源和授权状态；
- [ ] 照片、视频帧和证据图先通过 safe-media layout，再进入 Remotion；
- [ ] 每个比例独立排版，不拉伸、不静默裁切；
- [ ] 使用 360px 小图预览检查标题、人物眼睛和关键证据；
- [ ] 运行尺寸、溢出、模糊、人物遮挡、安全区和重复图检查；
- [ ] 所有候选保持 `candidate_only`，由人工决定是否发布。

## 六、没有专用照片时的降级顺序

1. 有清晰、表情自然、可安全裁切的视频帧：显式标记 `video_frame`；
2. 证据本身能完成承诺：改用 `evidence_visual`；
3. 没有合适人物或证据：使用 `typography_only`；
4. 不使用 AI 生成或换脸来冒充本人真实拍摄。
