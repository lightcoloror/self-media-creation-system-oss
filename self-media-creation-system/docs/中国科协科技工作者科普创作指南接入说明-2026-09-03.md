# 中国科协《科技工作者科普创作指南》接入说明

## 结论

《科技工作者科普创作指南》登记为现有自媒体管线的官方科普方法依据，不作为医疗诊疗标准、保险监管或合同依据，也不作为平台流量规则。它只增加条件式审核，不创建新的内容状态机。

官方通知：中国科协办公厅，文件日期 2026-04-15，官网发布日期 2026-04-17。

- 官方页面：https://www.cast.org.cn/xw/tzgg/KXPJ/art/2026/art_f5ab20b92cdf424e8683c31c19ec95fe.html
- 机器来源卡：`docs/references/cast-science-popularization-guide-2026.v1.json`

## 触发范围

新稿或实质修改稿只要包含科学、技术、健康、医学或医疗保险交叉事实主张，就在正文冻结后、视觉或视频制作前运行 `science-popularization-review.v1`。纯个人感受且不包含上述主张时记录为不适用，不强行套用。

## 三项新增审核

1. 科学性审核：当前权威来源、资料台账、数据和引用时效、概念定义、争议呈现、局限及个案边界全部通过；健康或医学内容保留人工专业审核。
2. 目标受众可读性审核：至少一名目标受众代表查看冻结正文，留下轻量反馈证据；术语、结构和信息密度问题已经处理。
3. AI 使用审核：不得向 AI 路线输入未脱密的非公开或敏感资料；AI 不能成为事实证据；AI 参与时必须完成人工事实复核，并在发布包中重新评估当前平台或机构的标识要求。

## 与现有管线的关系

```text
选题与公众问题
→ research/evidence 与事实卡
→ 母稿、故事或解释结构
→ human voice 与正文冻结
→ science-popularization-review（适用时）
→ 标题/封面/开场与视觉、视频制作
→ 保险医疗合规、隐私和发布包
→ 人工发布
```

正文、证据、目标受众反馈或 AI 使用情况发生变化，旧科普回执失效并重跑。该回执只有 `candidate-only / review-required / manual-only` 权限。
